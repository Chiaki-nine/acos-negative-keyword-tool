亚马逊搜索词否词工具（浏览器本地处理版）

版本：4.0

一、这是什么

这是纯静态网页版本。使用者打开网址后，可以上传亚马逊搜索词报告、填写产品标题和后台 ST，并导出否词建议 Excel。

报告的读取、分析和 Excel 生成都在使用者自己的浏览器中完成，不需要 Python、Node、安装包或本地端口，也不会把报告上传到服务器。

二、本地查看

直接双击 index.html 即可打开。部分公司电脑会限制本地网页脚本；遇到这种情况，请把整个文件夹发布到静态网站后使用。

三、发布成固定网址（推荐 Cloudflare Pages）

1. 注册或登录 Cloudflare。
2. 进入 Workers 和 Pages，创建 Pages 项目。
3. 选择“直接上传”方式。
4. 上传本文件夹中的全部内容，确保 index.html 位于网站根目录。
5. 发布后会得到一个 https://项目名.pages.dev 的网址，把该网址分享给其他人即可。

也可以部署到 GitHub Pages、Netlify、Vercel 或任何普通静态网站托管服务。此版本不需要服务器端代码。

四、使用方法

1. 打开网页。
2. 选择 .xlsx 或 .xls 搜索词报告。
3. 可选：填写多个产品标题和后台 ST。
4. 点击“开始本地分析”。
5. 查看词组否定、精准否定和暂缓否定建议。
6. 点击“导出否词建议表”。

五、重要口径

- ACOS = 广告花费 / 广告销售额。
- “关键词是否否定”对应报告中的“关键词”列。
- 精准否定候选对应“用户搜索词”列。
- 标题/ST 重点词、季节/天气词和数据尚未成熟的词会优先保护或暂缓否定。
- 导出工作簿包含分析总览、产品词库、词根分析、搜索词分析、否词建议和原始数据。

六、更新网站

以后更新版本时，重新上传整个文件夹并覆盖旧文件。不要只替换 index.html，因为分析逻辑和 Excel 组件也需要同步更新。
